# 查询天数参数化与 90 天上限

日期：2026-09-24（Asia/Shanghai）。任务类型：查询参数、宿主技能、验证与文档。用户要求天数由用户表述指定，超过 90 天时提示并限制。

## 结果与使用

当前源码与本机 WorkBuddy 安装副本已支持 `collect --days N`，范围为 1～90 个自然日，包含当天，截止任务开始时刻。首轮 7 天不再是每次运行的硬条件；用户未指定时间范围时，从 `config/p0-baseline.json.dateRange.days` 读取默认值，当前仍为 7。运行参数不改写此配置或历史快照。

| 用户表述 | 宿主动作 |
|---|---|
| 最近三天 / 最近 3 天 | `collect --days 3` |
| 今天 | `collect --days 1` |
| 近两周 | `collect --days 14` |
| 最近 90 天 | `collect --days 90` |
| 最近 100 天 | 提示“查询范围不能超过 90 天，请指定 1～90 天”，停止采集 |
| 没有指定时间范围 | 省略 `--days`，使用配置默认值 |
| 三个月等无法唯一换算的范围 | 先澄清具体天数，不擅自当成 90 天 |

自然语言理解由当前 Codex / WorkBuddy 会话完成，技能规定将明确天数转换为参数；业务程序校验参数并计算窗口。没有在采集程序中新增自然语言模型或另一套模型 API。超限不截断、不回退默认，也不拆分成多次请求绕过。

```powershell
# 本轮为包含当天的最近 3 个自然日
pnpm run assistant collect --days 3
# 阶段 CLI 与诊断入口同样支持
pnpm run collect:p1 --days 3 --site ccgp
# 下列调用拒绝执行，退出码 1
pnpm run assistant collect --days 91
```

以 2026-09-24 12:00（北京时间）为开始时刻：1 天从 09-24 00:00 起；3 天从 09-22 00:00 起；90 天从 06-27 00:00 起。它是自然日窗口，不是从当前时刻回退 N×24 小时。示例日期不是固定查询日期。

## 实现、接口与文件

| 文件 / 范围 | 变化 |
|---|---|
| `src/run/window.ts` | 统一 1～90 天校验；`createWindow(now, days)` 要求调用方提供天数，不再内置 7 天 |
| `src/run/config.ts` | 校验默认配置天数，允许可选本次覆盖；保留北京时间、含当天、广东、手动等其他边界 |
| `src/cli.ts`、`src/assistant/cli.ts` | 新增并传递 `--days`，更新帮助；错误在创建运行目录、取得公共锁和浏览器启动前返回 |
| `src/model.ts`、`src/run/collect.ts` | `RunConfig.days` 必填；生成实际窗口并传给两站适配器；新报告增加 `queryDays` |
| `skills/tender-assistant/SKILL.md`、`references/workflow.md` | 自然语言天数映射、默认条件、超限提示、拒绝规则及报告范围核对 |
| `test/unit/query-days.test.ts`、`window.test.ts` | 配置覆盖、日期边界、CLI 参数与无副作用拒绝、实际采集函数的受控浏览器回归 |
| `test/unit/assistant-cli.test.ts`、`skill-install.test.ts` | 统一入口和两个宿主包装器保留超限错误与退出码 |
| `test/unit/analysis-fixtures.ts`、`pagination.test.ts`、`results.test.ts` | 既有合成样本明确传入其原有 7 天，不改变历史测试含义 |
| `config/sites.json`、`AGENTS.md`、`README.md`、`schemas/README.md` | 更新当前查询计划、规则、命令与字段契约；历史能力记录保留 |
| P1 记录、总执行方案、最终技术方案、维护手册、WorkBuddy 安装说明、`服务交互时序图.html`、本文 | 同步当前行为，P0/P6 与旧实测继续保留原日期语境 |

`QUERY_DAYS_EXCEEDED` 表示超过 90 天；`INVALID_QUERY_DAYS` 表示非正整数或非法格式。两者退出码为 1；缺少参数值或未知选项由参数解析器拒绝。默认配置同样必须为合法数值，不能靠本轮覆盖掩盖损坏的默认配置。

新报告的 `queryDays` 记录本次天数，既有 `window` 结构保持不变。P3 继续使用输入报告原窗口，旧报告没有 `queryDays` 仍可读取。历史归档、模型结果、通知账本不迁移或改写。站点访问频率、页数、详情抽样和运行时间上限保持原值；90 天参数被接受不等于在这些上限内必然完整采集。
