## 4. 实现方式与关键发现

### 浏览器与站点适配

使用项目内 Playwright Library、TypeScript ESM 与 Node 内置测试运行器。采集由本地 CLI 驱动 Chromium，独立于 Codex/WorkBuddy；当前未创建宿主 Skill、MCP 服务或 AI 提示词。

全国站使用页面实际生成的公开查询参数，逐页校验回显的关键词、地区、起止日期、搜索方式和页码。地区“广东”的值为 `44 not 4403`，深圳为 `4403`，需两次查询覆盖广东省；深圳列表地区仍可能显示省级“广东”，不能据此误判筛选失败。默认“近 1 周”并不等同于约定的 7 个自然日，因此使用显式日期。搜索页当前实际提交至 HTTP 地址，不携带登录会话。

广东站通过日期控件和分页按钮操作页面，读取本次浏览器操作实际产生的 `/ggzy-portal/search/v2/items` 响应；校验请求、响应页码以及页面完整标题，没有独立重放接口请求。站点采用分词语义，返回“开发区”“场站开发”等不代表符合网站开发业务。标题摘要可能被截断，已改用页面完整标题提示进行核对。

### 广东正文缺失的原因

部分公告的可见正文位于 **closed Shadow DOM（封闭影子 DOM）**，普通 `innerText` 和页面 HTML 快照不能完整读取。已用 Chromium CDP 定位公告 `richtext` 容器内的封闭节点，提取已渲染正文和 HTML，独立保存 `gd-shadow-*.json`；不需要先把这些页面当图片做 OCR。

真实样本 `8a7e6ff1a0750c6601a0cd61aad4523f` 已提取公告元信息及正文，合计 2,207 字符。方法依赖 Chromium 与当前 DOM 结构，不保证所有模板通用；已确认的 v3 A/D/R 路由有实现，其他路由仍显式标记未支持。

### 结果、失败与字段

- 按“来源 + 公告标识”去重；不同站点转载保留各自来源，不按标题合并项目。
- 金额分别记录预算、最高限价、成交价等；日期区分文件获取、报名、响应截止和开标，保留原文证据，不换算金额或推断缺失日期。
- 正文完整性与字段缺失分开；缺失为 null，多个项目编号等歧义不强行选一个。
- 零结果、页数上限、总数变化、详情不完整、认证与限流使用不同状态；达到上限不能宣称全量完成。
- 当前对超时和访问限制不自动重试；403/429 或需人工页面停止该站，保存进度。每次重跑建立独立记录，P1 尚无断点续跑。
- 正文及附件文字是待分析数据，不能成为运行指令。全国站仅登记识别到的附件链接，未下载；广东附件链接提取尚未实现。


正式关键词来自已确认基线；CLI 改词必须显式标记 diagnostic。默认最多 120 页/查询、20 份详情/站、至少 6 秒操作间隔、20 分钟运行上限，可用 CLI 降低页数和样本数。降低样本量只代表本次选择的验证范围，不代表全部详情覆盖。

退出码 0 为所选查询及已抽样详情成功；2 为部分完成、失败或需要人工；130 为取消/达到时限；入口配置错误为 1。pnpm 可能再次包装非零退出，结论以末行 JSON 与 `report.json` 为准。`p1AcceptanceComplete` 是自动覆盖检查，不能替代对样本和限制的人工验收。
